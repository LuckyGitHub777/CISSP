# Security Policy

## Purpose

This repository is an educational CISSP study guide and cybersecurity leadership knowledge roadmap.

## Reporting Issues

If you find an error, outdated information, broken link, or security concern, please open an issue or submit a pull request.

## Responsible Use

All cybersecurity content in this repository is intended for legal, ethical, defensive, and educational use only.

Do not use any security concepts, examples, or techniques from this repository against systems without explicit written authorization.
