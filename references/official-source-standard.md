# Official Source Standard

## Official Authority

Use ISC2 official guidance as the authority for:

- CISSP exam format
- CISSP domain list
- CISSP domain weights
- CISSP experience requirements
- CISSP AI guidance
- CISSP certification policies

## Validation Rule

Exam facts and domain weights are sourced claims. For exam planning, verify them through ISC2 official guidance.

## Maintenance Rule

This repository should be reviewed during maintenance because cybersecurity domains, exam outlines, AI guidance, laws, technologies, and security practices change.

## Legacy Rule

Legacy CISSP materials may support foundational learning, but they do not override ISC2 official guidance.

## Public GitHub Rule

Do not upload copyrighted books, proprietary guides, copied question banks, paid training content, or full copyrighted explanations.

## Applied Security Reality

CISSP knowledge should be applied to:

- AI governance and AI security
- Cloud and SaaS risk
- Identity-first security
- Zero Trust architecture
- Software supply chain security
- API security
- Data privacy and governance
- Resilience, incident response, and continuity
- Vendor and third-party risk
- Security metrics and evidence-based assurance
