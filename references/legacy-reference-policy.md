# Legacy Reference Policy

This repository may use legacy CISSP materials for historical awareness and foundational learning, but it does not reproduce copyrighted content.

## Allowed

- Original notes
- Original summaries
- Fresh explanations
- Concept maps
- Personal study structure
- Official-source validation
- Short references to historical changes

## Not Allowed

- Uploading copyrighted PDFs
- Copying full chapters
- Copying proprietary question banks
- Copying paid practice exam explanations
- Presenting legacy exam facts as official guidance
- Treating legacy domain models as exam-governing structure

## Standard

Use legacy materials for background.

Use ISC2 official guidance for exam claims.
