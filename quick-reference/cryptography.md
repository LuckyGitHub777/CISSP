# Cryptography

## Core Concepts

- Confidentiality
- Integrity
- Authentication
- Nonrepudiation
- Symmetric encryption
- Asymmetric encryption
- Hashing
- Digital signatures
- Certificates
- PKI
- Key management

## Leadership Rules

- Do not create custom cryptography.
- Protect keys as critical assets.
- Match cryptographic controls to risk, data sensitivity, and operational context.
- Cryptography fails when implementation, key storage, identity, or operations fail.
