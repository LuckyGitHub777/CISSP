# Incident Response

## Core Flow

1. Prepare
2. Detect
3. Analyze
4. Contain
5. Eradicate
6. Recover
7. Improve

## Evidence Rules

- Preserve logs.
- Protect chain of custody.
- Document decisions.
- Separate facts from assumptions.
- Retest controls after remediation.

## Decision Rules

- Protect people first.
- Preserve mission continuity.
- Contain harm.
- Escalate based on impact.
- Communicate through approved channels.
- Retain evidence for investigation and lessons learned.
