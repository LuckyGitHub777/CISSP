# Contributing

## Purpose

This repository is a CISSP study guide and cybersecurity leadership knowledge roadmap.

Contributions should improve clarity, accuracy, structure, ethical use, and source discipline.

## Contribution Rules

- Use ISC2 official guidance for exam claims.
- Use original wording.
- Do not copy copyrighted books, paid training content, proprietary explanations, or question banks.
- Do not add offensive security content that enables unauthorized activity.
- Keep all cybersecurity examples legal, ethical, defensive, and authorized.
- Treat AI as a cross-domain cybersecurity issue, not as a separate CISSP domain.
- Mark legacy materials as background learning only.
- Prefer concise, readable, plain-language explanations.

## Pull Request Checklist

- No copyrighted content
- No copied question bank material
- No unclear affiliation claim
- No exam claim without official source support
- No unsafe or unauthorized security guidance
- No AI domain added outside the eight CISSP domains
